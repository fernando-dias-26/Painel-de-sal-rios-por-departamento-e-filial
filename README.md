# Painel de salários por departamento e filial (Power BI)

Painel de RH que mostra onde está a folha salarial: salário por departamento, por filial e por colaborador, com filtro por faixa salarial.

## Demo
Abra o `index.html` (ou a página publicada) para ver uma versão interativa em HTML, CSS e JavaScript. Os nomes e valores da demo são **fictícios**.

## Baixar o projeto
O relatório original do Power BI está em [`modelos/painel-salarios.pbix`](modelos/painel-salarios.pbix). Para abrir, use o Power BI Desktop (gratuito).

## O que o painel mostra
- Massa salarial por departamento
- Massa salarial por filial e por colaborador
- Colaboradores por departamento
- Filtro por faixa de salário

## Ferramentas
Power BI Desktop (relatório) · HTML, CSS e JavaScript (demo)
